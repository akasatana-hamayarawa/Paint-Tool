GitHub Pages で無料公開する方法

サーバー不要で誰でもアクセスできるURLを作ろう！

ステップ 1: GitHubでリポジトリを作成 GitHubにログインし、「New repository」から新しいリポジトリ（例: my-paint-app）を作成します。
ステップ 2: ファイルを保存してアップロード このファイルを index.html という名前で保存し、作成したリポジトリにアップロード（またはコミット）します。
ステップ 3: GitHub Pagesの有効化 リポジトリの Settings > Pages を開き、Build and deployment の Source を 「Deploy from a branch」にし、Branch を main (/root) に設定して Save します。
完了！
数分で https://ユーザー名.github.io/リポジトリ名/ で全世界に公開され、友達を招待してペイントできます！
